# Alke Wallet

## Descripción

Alke Wallet es una aplicación web de billetera digital desarrollada como proyecto del Módulo 2 del Bootcamp de Desarrollo Web.

La aplicación permite a los usuarios iniciar sesión, consultar su saldo, realizar depósitos, enviar dinero a contactos y visualizar el historial de movimientos realizados.

## Tecnologías Utilizadas

* HTML5
* CSS3
* Bootstrap 4
* JavaScript
* jQuery
* Local Storage

## Funcionalidades

### Inicio de Sesión

* Validación de credenciales.
* Mensajes de éxito y error utilizando Bootstrap.

### Menú Principal

* Visualización del saldo disponible.
* Navegación entre módulos.

### Depósitos

* Registro de depósitos.
* Actualización automática del saldo.
* Confirmación visual de la operación.

### Envío de Dinero

* Búsqueda de contactos.
* Agregar nuevos contactos.
* Validación de formularios.
* Actualización automática del saldo después de la transferencia.

### Últimos Movimientos

* Registro de depósitos y transferencias.
* Filtro por tipo de movimiento.
* Visualización dinámica de transacciones.

## Persistencia de Datos

La aplicación utiliza Local Storage para almacenar:

* Saldo del usuario.
* Contactos registrados.
* Historial de movimientos.
